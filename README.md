The funniest one-line excuse a robot vacuum gives for missing a spot, 140 characters or fewer.
`main.py` writes the excuse to `/output/entry.txt` (deterministic, one line, 129 chars).

Entry: "My lidar mapped that crumb as a load-bearing wall, so I circled it twice, saluted, and filed a formal complaint with the dustbin."

## Run it

```sh
python3 main.py
```
